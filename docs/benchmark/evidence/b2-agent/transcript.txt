  - **No repository changes:** `UpdateAsync` in both repositories already checks
  and increments the version atomically and writes the new version back to the
  item it was given.

  - `priority` is required, so a missing value returns 400 instead of silently

  version", so this goes slightly beyond it.
  - Sending the priority the todo already has still counts as an update and
  increments `version`.
  - No MCP tool is added.
